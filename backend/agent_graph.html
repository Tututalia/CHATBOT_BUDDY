🛠️ Available Agent Tools

📦 recommendation_agent

Purpose: Shows product recommendations

Triggered: User wants to browse products

📊 inventory_agent

Purpose: Checks product availability

Triggered: User selects a product

💳 payment_agent

Purpose: Processes online payment

Triggered: User chooses online purchase

🚚 fulfillment_agent

Purpose: Handles order fulfillment

Triggered: After payment or offline selection

🎁 loyalty_agent

Purpose: Awards loyalty points & coupons

Triggered: After order fulfillment

📝 post_purchase_agent

Purpose: Sends feedback & support info

Triggered: Final step after loyalty

⚡ Key Features:
  • Non-linear flow - LLM decides tool calls dynamically
  • Context-aware - Remembers entire conversation
  • Intelligent routing - Tools called only when needed
  • Natural conversation - Feels human-like, not scripted
